# 🎂 Birthday Project

A personalized interactive frontend project created as a birthday surprise for my best friend.
Built as a creative side project while exploring frontend development, responsive UI design, and interactive web experiences.

---

## 🌐 Live Demo

👉 https://mr-rup.github.io/Birthday_project/

---

## ✨ Features

* 🎉 Interactive birthday-themed interface
* 📱 Responsive design for multiple screen sizes
* 🎨 Custom styling and visual elements
* ⚡ Lightweight and smooth user experience
* 💫 Creative frontend experimentation

---

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* GitHub Pages

This project was built as a fun and meaningful frontend experiment outside of my usual AI and research-oriented workflows. It provided an opportunity to explore UI structuring, styling, responsiveness, and interactive design in a more creative setting.
